# Общественная сеть Нокса

Небольшой портал в стилистике любительских сайтов начала 2000-х для частного ролевого сервера. В проекте есть новости от администрации, барахолка выживших, один профиль на учётную запись и компактная панель управления. Весь лор и визуальное оформление созданы специально для проекта.

## Требования

- Python 3.10 или новее
- Django 5.2 и Pillow из файла `requirements.txt`

## Запуск на Windows

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo_data
python manage.py runserver
```

Откройте <http://127.0.0.1:8000/>. На macOS или Linux окружение активируется командой `source .venv/bin/activate`, остальные команды те же.

Команду заполнения можно запускать повторно. Она создаёт и переводит демонстрационные данные, а также восстанавливает следующие пароли:

| Роль | Имя пользователя | Пароль |
| --- | --- | --- |
| Администратор | `администратор` | `НоксАдмин!1993` |
| Выжившие | `выживший1` — `выживший5` | `Выживший!1993` |

Эти данные предназначены только для локальной демонстрации. Перед публикацией сайта смените все пароли.

## Управление сайтом

Войдите как администратор и откройте `/control-panel/`. В панели можно:

- создавать новости и менять их видимость;
- изменять или удалять любые объявления;
- создавать, отключать и редактировать учётные записи;
- менять название сайта, приветствие, экстренное сообщение и состояние сервера.

Системная панель Django доступна по адресу `/admin/`. Открытая регистрация намеренно отключена.

## Структура проекта

```text
config/       настройки Django и корневые маршруты
core/         главная страница, настройки и панель управления
accounts/     профили и управление пользователями
news/         открытые и закрытые новости
marketplace/  объявления и проверка владельца
templates/    общие шаблоны и страницы приложений
static/       стили и минимальный сценарий
media/        загруженные изображения
```

## Проверка

```powershell
python manage.py check
python manage.py test
```

После изменения моделей выполните `python manage.py makemigrations`, проверьте созданные миграции и примените их командой `python manage.py migrate`.

## Настройка для публикации

Перенесите переменные из `.env.example` в настройки среды размещения. Django не загружает этот файл автоматически. Для опубликованной версии задайте новый секретный ключ, разрешённые домены, отключите режим отладки и используйте защищённое соединение. Изображения проверяются библиотекой Pillow и ограничены размером 3 МБ. Не добавляйте в репозиторий `.env`, `db.sqlite3` и содержимое каталога `media/`.
